## What I'm building

- [PatchBay](https://github.com/Nitish-1303/patchbay-demo-payments) - a self-maintaining API agent. It watches third-party APIs for breaking changes, reproduces the break against your real code, writes the minimal patch, proves it with your own test suite, and opens a PR with the evidence. The demo repo runs the whole loop on a simulated Stripe breaking change.
- [CipherBill](https://github.com/Nitish-1303/CipherBill) - privacy-first invoicing and settlement on Starknet: shielded balances, private transfers, selective disclosure for accounting. Live at [cipher-bill.vercel.app](https://cipher-bill.vercel.app).
- [cookbook-canary](https://github.com/Nitish-1303/cookbook-canary) - proves every example in a repo still runs, each on its own hardware-isolated microVM. 125 tests, live report dashboard.
- [Lumina](https://github.com/Nitish-1303/lumina-OS) - an iMessage-native life OS: daily briefings, accountability and decision support over chat, powered by Gemini.
